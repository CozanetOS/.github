# .github
CozanetOS org-wide GitHub configuration, templates, and workflows.

## ⚠️ MANDATORY: Read Before Writing Code

Every AI assistant, coding agent, and developer MUST read [`COZANET_CONSTITUTION.md`](./COZANET_CONSTITUTION.md) before proposing changes, generating code, modifying UI, or creating features in any CozanetOS repository.

The Constitution contains:
- **UI Protection Guard** — prevents AI agents from rewriting the custom CSS UI
- **AI Agent Rules** — what AI must never do and must always do
- **Architecture Laws** — non-negotiable rules for the codebase
- **Change Workflow** — mandatory build → deploy → verify cycle
- **Repository Ownership** — which repos are live vs scaffold

**Violations of the Constitution are bugs, not preferences.**
